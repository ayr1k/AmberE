# Security

[简体中文](docs/zh-CN/SECURITY.md)

Do not publish tokens, passwords, account stores, private logs or exploit details in public issues. Open an issue in ayr1k/AmberE without sensitive information to request a private contact channel with the maintainer.

Use temporary data when testing. No exhaustive security audit or certification is claimed. Preserve MPL-2.0 and upstream notices when reporting or fixing shared-core issues.
